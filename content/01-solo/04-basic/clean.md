cleanはGitが追跡していないファイルを削除します。コミットにない解析データや実験メモも対象になり得るので、消してよいこととバックアップを確認する用途に限ります。

git clean -n は未追跡ファイルの削除候補を表示し、確認後に -f で実際に削除します。-nd は未追跡ディレクトリも含む候補を表示し、それを削除する場合は -fd です。同じ作業場所・同じ条件の候補を確認してから判断します。確認後にファイルが増えれば対象も変わります。

## コマンド

```sh
git status --short
git clean -n
# 候補を確認し、必要なデータを退避した後に限る
git clean -f
# ディレクトリも対象にする場合は、別途確認する
git clean -nd
# 確認後の削除例: git clean -fd
```

## 要点

cleanは未追跡を削除。-nで候補を見てから判断する。

## 付箋

### clean-lecture [講義]

未追跡データは、cleanのあとGitから復元できません。

### clean-study

既定では.gitignoreの対象を除外します。-xを付けると無視対象も削除範囲に入るため、この教材の実行例には含めません。-fdは通常、別のGitリポジトリをさらに強制して消す指定ではありません。
