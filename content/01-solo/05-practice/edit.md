練習フォルダーをエディターで開き、hello.pyを作成します。内容を print("Hello, world!") の1行にして保存してください。Pythonの実行環境がなくてもGitの演習は進められます。

git statusにhello.pyがUntracked filesとして表示されることを確認します。エディターで保存できても、まだGitの履歴には記録されていません。

## コマンド

```sh
git status
```

## 要点

まずファイルを保存し、Gitからどう見えるか確認する。

## 付箋

### practice-file-name [講義]

hello.py.txtになっていないか、ファイル名も確認しましょう。
