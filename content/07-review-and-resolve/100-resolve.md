どちらか一方を採用しても、両方を組み合わせても、新しい表現に書き直してもかまいません。今回は「みなさんこんにちは!」と表示する形にします。競合マーカーをすべて取り除き、通常のPythonコードとして保存します。

大切なのは、ボタンで機械的に片方を残すことではなく、Issueや相手の変更意図を確かめて完成形を決めることです。greet関数は、定義しただけでは挨拶を表示しません。下の確認例はPythonから関数を呼び出して、編集した結果を確かめます。

## コマンド

```sh
# hello.py の完成形
def greet():
    print("みなさんこんにちは!")

# 保存した後、ターミナルで確認する
python -c "from hello import greet; greet()"
```

## 要点

人が完成形を編集し、実行して確かめる。

## 付箋

### resolve-meaning [講義]

両方の行を残しただけで、仕様として正しいとは限りません。何を表示する関数なのかを確認します。
