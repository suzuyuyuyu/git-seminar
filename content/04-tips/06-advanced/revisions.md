HEAD~2は第一親を2回たどったコミットです。HEAD^またはHEAD^1は第一親、HEAD^2は第二親を指定します。^2は「2つ前」ではなく、第二親があるマージコミットなどで使います。

タグは特定の版に名前を付けます。既存のタグはgit show v1.0のように参照できます。タグの作成は次のスライドで扱います。タグはブランチのように新しいコミットへ自動で進みません。~や^を含む指定はシェルに解釈させないようクォートしています。

## スライド説明

HEADやブランチ名から親commitをたどり、表示・比較する版を指定します。

過去の版や、merge commitの親を調べるときに使います。

`HEAD~2` は第一親を2回たどります。`HEAD^2` は第二親を選ぶ指定で、2つ前という意味ではありません。

## コマンド

```sh
git show 'HEAD~2'
# HEAD に第二親がある場合
git show 'HEAD^2'
```

## 要点

~は第一親をたどる回数、^はどの親を選ぶか。

## 付箋

### revisions-lecture [講義]

コミットID、相対参照、タグは、版を指定する別の書き方です。

### revisions-study

HEAD~2は時刻順に並べたログの上から3行目とは限りません。HEAD^2に第二親がなければエラーです。タグを共有するなら git push origin v1.0 のように対象を指定します。
