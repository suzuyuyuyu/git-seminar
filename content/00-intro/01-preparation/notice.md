この教材では、コマンドや用語を英語で表記することがあります。端末の例にある `$` や `❯` は入力を待つ記号です。コマンド本体だけを入力し、出力や作業場所の表示は入力しません。例のURLやユーザー名は、自分の値に置き換えます。

Gitの仕組みを一度ですべて覚える必要はありません。まずは自分のファイルで保存・記録・共有を繰り返し、必要になったときに基本・標準・応用のコマンドを読み返してください。自学習表示は詳しい説明、講義表示は同じStepの図と要点を使います。

実行する前に現在のフォルダーと変更の状態を確認します。教材に表示されたコマンドは説明用で、Webページから自動実行されません。

## コマンド

```sh
git --version
# git version ... と表示されることを確認
```

## 要点

入力するコマンドと出力を見分け、少しずつ手を動かして学ぶ。
