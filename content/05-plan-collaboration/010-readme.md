初めてリポジトリを開いた人は、どのファイルを実行すればよいか、何を準備すればよいかを知りません。README.mdに研究コードの目的、必要な言語やライブラリの版、環境の準備、実行コマンド、期待する出力を書きます。自分が数か月後に再実行するための手順にもなります。

この教材のhello.pyなら、Pythonの確認方法と実行方法、表示される挨拶があれば試せます。実データが別の保存先にある場合は、その入手手順とアクセス条件を説明し、共有してはいけない内容そのものをREADMEへ貼り付けないようにします。

## コマンド

```sh
python --version
python hello.py
```

## 要点

READMEは、他の人が実行できる入口にする。

## 付箋

### readme-fresh [講義]

書いた手順を、まだ環境がない人に試してもらうと抜けに気づけます。
