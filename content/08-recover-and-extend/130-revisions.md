HEAD~2は第一親を2回たどったコミットです。HEAD^またはHEAD^1は第一親、HEAD^2は第二親を指定します。^2は「2つ前」ではなく、第二親があるマージコミットなどで使います。

タグは特定の版に名前を付けます。例のv1.0を作ると、以後はgit show v1.0でその版を確認できます。タグはブランチのように新しいコミットへ自動で進みません。~や^を含む指定はシェルに解釈させないようクォートしています。

## コマンド

```sh
git show 'HEAD~2'
# HEADがマージコミットの場合だけ
git show 'HEAD^2'
git tag -a v1.0 -m "解析の基準版"
git show v1.0
```

## 要点

~は第一親をたどる回数、^はどの親を選ぶか。

## 付箋

### revisions-lecture [講義]

コミットID、相対参照、タグは、版を指定する別の書き方です。

### revisions-study

HEAD~2は時刻順に並べたログの上から3行目とは限りません。HEAD^2に第二親がなければエラーです。タグを共有するなら git push origin v1.0 のように対象を指定します。
