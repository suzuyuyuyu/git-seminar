## 作成方法

Adobeプラグインには既存AIの書き出し・データ差し込み機能があるが、任意の図形を配置する編集機能はないため、MacのIllustrator 2026を画面操作した。対象ページだけを最大7ページずつリンク読み込みし、ドキュメントをRGBにしてから「透明部分を分割・統合」でベクトル100%、テキストのアウトライン変換を指定した。SVGはアートボードごとに出力した。生成AIで図を描き直す処理は行っていない。

通常読み込みではCenturyGothic、GenSenRounded2JP-M/Rの不足で文字が代替された。リンク読み込みからアウトライン化すると元の字形を保持できた。CMYKの既定設定では色が変わったため、RGB版を最終版とした。失敗・比較用の下書きは`tmp/illustrator-review/`に分離した。

## 制約と範囲

- 合計45枚のうち29枚は画像要素を含まないベクター。PDF7・8・9・21・22・42とPPT94〜103には画像がある。原図確認用として保管し、公開用の純ベクター図としては採用しない。イラストの元SVGは`docs/assets/illustrations/`にある。
- 文字はパスなので字形を保つ一方、文字列としては編集・検索できない。文言の変更には元フォントの用意、または文字の組み直しが必要。

- RGBで保持したが、色管理された異なるアプリ間での色差を数値で保証する検証はしていない。
